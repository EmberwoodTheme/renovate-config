## Usage

The purpose of this repository is to store all of Emberwood's custom
[Renovate](https://docs.renovatebot.com/) configuration.

This is a fork of [Catppuccin's configuration](https://github.com/catppuccin/renovate-config)
with modifications to use Emberwood's [Kindling](https://github.com/EmberwoodTheme/kindling).
